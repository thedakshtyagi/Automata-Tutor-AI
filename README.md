# Automata-Tutor-AI
AutomataTutor AI: Uses structured multi-step prompting and few-shot examples to convert formal automata, grammar, and computability problems into clear step-by-step derivations, counterexamples, and exam-ready explanations.

**# AutomataTutor AI 🧠⚡

AutomataTutor AI is an interactive, LLM-powered educational platform designed for computer science students mastering **Formal Languages, Automata Theory, and Computability**.

## Features
- **DFA / NFA Construction:** Step-by-step state transition tables and formal 5-tuple definitions.
- **CFG & Chomsky/Greibach Normal Forms:** Multi-step grammar conversions with verification.
- **P vs NP & Decidability Helper:** Structured chain-of-thought proofs and reducibility logic.
- **Edge-Case Validation:** Automatic verification of empty string (ε) and boundary cases.
- **Multi-Model Engine:** Powered by OpenAI GPT-4o, Claude 3.5 Sonnet, and Google Gemini 1.5 Pro via prompt engineering workflows.
